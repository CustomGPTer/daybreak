Release notes

What changed in each version of Daybreak. The newest is at the top.

Version 1.0 21 November 2026Latest

  • First release.
  • Wake to any song, several songs that change each morning, a radio station, your own music or one of ten built-in tones.
  • Gentle wake with a sunrise screen, wake-up tasks, repeat until I'm up, and an optional are-you-up check.
  • Days off, holiday dates and UK bank holidays, chosen per alarm.
  • World clock, timers, stopwatch, bedtime, widgets and a backup file.

Checking your download

The file for version 1.0 is called Daybreak.apk. It is 57.5 MB (57,530,297 bytes). Its SHA-256 checksum is:

e4d1ad6a6ae78891bbe6d294b23a3e5da83101b53298a15693c967e97c75f41b

On Windows, run certutil -hashfile Daybreak.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
